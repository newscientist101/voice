# AGENTS.md

## Dev environment

- **Python:** Code should be writen in Python, targeting version 3.13.11
- **UV:** Utilize uv for installing modules and running scripts

## Requirements

Everything you build must utilize pipecat services, APIs, and SDKs. If anything does not seem to be possible with pure pipecat, look for relevent community integrations. You should always read the pipecat API before deciding how something will be done.

## Docs

The docs in docs/plan/ are meant to guide initial build attempts, not constrain implementation. If the plan docs contradict the pipecat docs, the pipecat docs take precedent.
